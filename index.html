getting started
welcome to bsp

The Bitcraft Settlement Planner lets you design settlement layouts on a hex grid before building them in-game. Paint terrain, place buildings with accurate footprints, terraform elevation, and preview everything in 3D.

The left panel has collapsible sections — click a header or press 1–5 to jump to a panel. The status bar at the bottom always shows your current mode and cursor coordinates.

moving around

The viewport is your workspace. Navigate with the mouse:

middle-drag
pan the view
scroll
zoom in/out
i
invert scroll direction

The grid starts at 100×100 hexes. You can resize it in the grid panel if you need more or less space. Coordinates are shown in the status bar as axial Q, R — the same system the game uses internally.

If you get lost, zoom out with scroll to find your bearings.
painting terrain

This is the default mode. Pick a color from the palette and click or drag on the grid to paint hexes. Mark out residential areas, farms, roads, districts — whatever your layout needs.

click
paint a hex
drag
paint an area
+ / -
brush size
dbl-click
add a text label

The palette has 12 presets, a custom color swatch (the rainbow one), and an eraser (checkerboard) that resets hexes to default. Brush size in the palette header controls how many hexes you paint at once.

The border/dashed swatch renders as a dashed outline — useful for marking claim edges or settlement boundaries.
placing buildings

Toggle stamp mode with the button or x. The buildings panel opens with a category dropdown and building selector covering all ~600 buildings from the game.

Select a building, then click on the grid to place it. The hover preview shows the exact hitbox shape from game data for accurate collision planning.

x
toggle stamp mode
q
rotate CCW (60°)
e / r
rotate CW (60°)
Each placement is independent — place the same building multiple times. Switch buildings from the dropdown without leaving stamp mode.
selecting & moving buildings

Once buildings are placed, you can select, move, rotate, and delete them:

shift+click
select a building (highlights yellow)
shift+click
on empty space — reposition selected building
q / e
rotate selected building in-place
del
delete selected building
esc
deselect / cancel
The reposition preview shows the footprint at the cursor so you can see exactly where it will land before committing.
terraforming

Toggle terraform mode with the button or t. This mirrors the in-game elevation system — select 7-hex tile clusters and set their depth (0–100). Boundary lines appear automatically.

t
toggle terraform mode
click
select a tile cluster
ctrl+click
multi-select tiles
esc
clear selection

Use the depth slider in the terrain panel to set elevation for all selected tiles. The baseline depth sets a default for new tiles. Spacer tiles between clusters inherit depth from neighbors via majority-vote — just like in-game.

Terraforming is optional. If you just want a flat layout with buildings, skip it.
3d visualization

Press 3 or click 3d view to switch to perspective rendering. Terrain extrudes based on depth values, and buildings render as colored prisms.

3
toggle 3D view
left-drag
orbit camera
scroll
zoom
h
toggle heightmap colors
b
toggle boundary lines
Terraform editing requires 2D view. Painting and building placement work in both.
saving & loading

Plans save as JSON files to your computer. Nothing is stored on a server — your plans are entirely local.

save
downloads current plan as .json
load
opens a file picker to load a saved plan
reset
clears everything (no undo!)

The plan name in the top bar sets the filename. Plans include all painted hexes, buildings with rotation, depth values, and labels. Share .json files with other players — they just load them into their own BSP.

Save often. No auto-save and no undo yet.
